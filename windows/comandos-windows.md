# Comandos windows



para leer un archivo

```
type archivo.txt
```

para ver cuantos usuarios hay en una maquina windows

```
net users  
```

para ver mas informacion acerca del usuario

```
net user <usuario>
```

para ver los privilegios que tenemos en una maquina windows

```
whoami /priv
```

para ver los usuarios loguedos

```
query user
```

```
systeminfo
```
